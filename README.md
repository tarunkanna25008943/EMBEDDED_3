# Exp-3: Implementation of Automatic Motion Detector Using PIR Sensor

## AIM

To design and implement an automatic security system that detects human motion using PIR sensor and activates an LED.

## APPARATUS REQUIRED

- Arduino
- PIR motion sensor
- LED
- 220 Ω resistor
- Laptop
- USB Cable

## PARAMETERS

- PIR sensor connected to a digital input
- LED connected to digital output
- PIR sensor is supplied with required operating voltage
- System remains in monitoring mode when no motion is detected
- LED is activated HIGH when motion is detected

## OUTPUT

## RESULT

The PIR home automation system was successfully simulated and implemented.
